## 复现附件范围

当前提供 60 查询开发对照与全库 300 查询三种策略的精简排名，支持离线重算指标。重新执行检索需另行准备语料、索引与模型。可选重排默认关闭，启用前按[配置说明](COLLECTION_RERANKING.md)准备本地模型缓存。

端到端评测提供方法与汇总，完整逐题产物保留在研发环境。账号凭据、用户数据库、模型权重和原始文库全文保持本地；源码、评测结果及历史运行记录分别标注对应范围与版本。
