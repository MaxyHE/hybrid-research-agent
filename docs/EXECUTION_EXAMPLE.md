## 本次说明了什么

运行时实际执行了任务分发、并行研究、任务额度分配、单轮动作限制及Writer交接；不是只在prompt中要求模型遵守预算。网页服务层可在无官网硬白名单条件下完成一次混合来源研究。

报告对两种方法的主要机制、实现入口与建议有所覆盖。9 月 12 日定位复核确认，“Front Row”搜索示例存在于 ReAct 图 1；此前 PDF 字形编码异常导致文本查找遗漏，现更正原来的无支持判断。引用存在性检查仍不等同于逐项事实复核；原始结果不改写。

恢复前一次尝试在Mac MPS张量操作中崩溃。修复将轻量重排固定在CPU，防止重复冷启动，并串行访问共享tokenizer与模型。三路本地文库检索验证通过后，仅恢复同题一次。研究任务与Web调用仍保持并行，不改变问题或任务预算。
