# 结果与测量范围

## 检索组件：60 条固定查询

同一语料、embedding 与 FAISS 索引，对比旧 raw top8 与 raw64 → Document 去重 → 最多 8 个候选。新增问题在检索前冻结。

| 指标 | 旧接口 | Document 接口 |
| --- | ---: | ---: |
| 指定目标 micro Recall@8 | 61/76，80.3% | 67/76，88.2% |
| 逐查询等权 Recall@8 | 82.2% | 87.5% |
| Document MRR@8 | 0.7978 | 0.8032 |
| 输出文档重复率 | 51.9% | 0% |
| 平均不同文档候选数 | 3.85 | 7.73 |
| 全部目标召回的查询 | 47/60 | 52/60 |

原 18 条开发查询目标召回保持 100%；新增 42 条单列 72.7% → 83.6%。两套语料分别为 20 篇研究论文和 76 篇 SciFact 摘要。76 是查询—指定目标对，不是穷尽相关文献标签。

48 条英文当前目标召回 100%，12 条中文 40%；主结果包含全部语言，不只选英文。使用同一个英语 MiniLM embedding，未做翻译。排名与指标由程序计算，新增标签由助手阅读语料后编写，非独立专家盲标。120 次本地检索、无生成或付费 API 调用。改变的是候选池扩展与去重组合，不单独归因给某一个动作。

## 托管模型：12 题质量评测

Web、Collection、Hybrid 各 4 题。每题 5 个固定检查项，以助手离线对照报告与当次保存来源评审；覆盖至少 4/5，核心交付成立，且无核心事实错误或来源模式违规，记为完成。

当前 H-off：故障恢复视图 11/12（91.7%），抽样声明完全支持 58/60（96.7%）。指定连接故障位置使用恢复尝试，其他保留首次；原失败与费用保存在研发仓库。

P1-H 对照同样 11/12，当前版统一费率费用高约 18.3%。该对照属于最终候选选型，不主张整体完成率或成本改善。费用来自已报告 token 估算，不是账单。

## 本地模型：30 题固定评测

Qwen v6.2：首次 16/30（53.3%），指定连接故障恢复后 17/30（56.7%）。三模式分别 6/10、6/10、5/10。覆盖得分 119/150，抽样声明完全支持 112/150。10 个文库任务的 25 个任务—论文目标全部发现并读取；这是多轮任务级覆盖，不是单查询 Recall@1。

后续版本处于开发验证，旧成绩不追改为新版成绩。当前公开准备重点是条件保留、多来源综合与官方实现核查。
