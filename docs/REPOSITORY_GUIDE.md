## 复现附件范围

当前提供60查询开发对照及全库300查询三种策略的精简排名与评分重算入口，见[评测附件](evaluation/README.md)。重排功能已可选接入发布版；默认关闭，需要按[配置说明](COLLECTION_RERANKING.md)准备本地模型缓存。排名重算不等于重新运行检索。

仓库提供通用配置样例，不包含账号凭据、用户数据库、模型权重或原始文库全文。源码、评测结果和演示分别标注对应范围与版本。
