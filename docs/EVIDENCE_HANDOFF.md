# Original-evidence handoff

研究中的摘要不应成为后续写作唯一可见的事实来源。原文交接模式让 Writer 同时看到研究结论和支持它的原文位置，并保留 subject、claim_role、conditions，区分当前方法结果、相关工作和一般背景。

## 使用

在启动服务前设置 `LDR_HYBRID_EVIDENCE_HANDOFF=located`。该选项仅用于托管路线；未设置时保留 H-off，显式配置的 Qwen 模型仍进入 Qwen 专用流程。运行元数据中的 writer_context_version 为 `located-attributed`。

主要代码为 `odr_baseline/located_handoff.py`。Researcher 从已抓取快照选择原文片段，运行时附上实际文本和位置；Writer 接收合并后的证据。来源编号由运行时映射成引用链接。范围定位、来源存在与预算由代码处理；语义归属和报告判断仍由模型完成。

## 新增完整 Hybrid 案例

问题：将 Self-RAG 接到已有文库研究助手，需要哪些模型能力、检索组件及代码适配？要求论文定义来自文库，实现依据来自作者仓库，并判断普通 OpenAI 兼容接口能否替代。

运行实际读取文库与 Web 的 7 个来源，完成 6 个研究子任务；71 次模型调用、56 次工具调用、876.917 秒。来源复核对五项核心要求评分 5/5。报告区分训练过的 Self-RAG 模型与普通生成模型，给出官方推理/检索入口，并区分配置与需要移植的控制逻辑。

这是一道新增端到端案例，不替代 H04，不合并成新的 12 题端到端成功率。报告偏长，部分原文位置仍为文本标记而非可点击链接；未实际运行报告建议的 Self-RAG 部署代码。原始全文快照及本机运行配置不公开。
