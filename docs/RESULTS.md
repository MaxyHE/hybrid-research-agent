# 结果与测量范围

## 主检索结果：完整 SciFact

5,183篇文档、14,940 chunks、300条官方test查询、339个相关文档对；all-MiniLM-L6-v2，recursive 1000/200，归一化FAISS flat。各行均以最终文档序列计算指标。

| 策略 | micro Recall@8 | MRR@8 | nDCG@8 |
| --- | ---: | ---: | ---: |
| 原始raw8，文档不补位 | 74.34% | 0.6115 | 0.6441 |
| raw64→首次Document去重→8 | 77.29% | 0.6139 | 0.6519 |
| 同raw64池内Cross-Encoder→8 | 79.06% | 0.6520 | 0.6815 |

重排模型为cross-encoder/ms-marco-MiniLM-L6-v2；标题与摘要输入，文档端512token截断。相对Document策略新增20个目标、丢失14个，净增6；Recall@5从73.16%略降至72.86%。这是候选扩展与固定池排序的组件对照，不是端到端研究完成率。后续选型已使用这批结果，不称独立未见验证。研发入口可选重排已验证，本发布副本尚未同步。

排除早期用过的10条官方题，290题Document→reranker的Recall@8为77.30%→79.14%。研发安全排名与分数已归档：全库6b01906、模型对照44a8717；结果文档3e33318。此处不暗示这些附件已经随发布副本分发。

## 多语言选型（开发材料）

E5-small全库英文Recall@8为74.34%，低于MiniLM Document策略的77.29%；20条预先冻结的中文译文配对为10.71%→57.14%（3/28→16/28目标）。没有采用其替换默认模型。中文译文为助手制作，不是官方中文benchmark。该结果支持跨语言取舍讨论，不列为整体检索升级。

## 检索组件：60 条固定查询

同一语料、embedding 与 FAISS 索引，对比旧 raw top8 与 raw64 → Document 去重 → 最多 8 个候选。新增问题在检索前冻结。

| 指标 | 旧接口 | Document 接口 |
| --- | ---: | ---: |
| 指定目标 micro Recall@8 | 61/76，80.3% | 67/76，88.2% |
| 逐查询等权 Recall@8 | 82.2% | 87.5% |
| Document MRR@8 | 0.7978 | 0.8032 |
| 输出文档重复率 | 51.9% | 0% |
| 平均不同文档候选数 | 3.85 | 7.73 |
| 全部目标召回的查询 | 47/60 | 52/60 |

原 18 条开发查询目标召回保持 100%；新增 42 条单列 72.7% → 83.6%。两套语料分别为 20 篇研究论文和 76 篇 SciFact 摘要。76 是查询—指定目标对，不是穷尽相关文献标签。

48 条英文当前目标召回 100%，12 条中文 40%；主结果包含全部语言，不只选英文。使用同一个英语 MiniLM embedding，未做翻译。排名与指标由程序计算，新增标签由助手阅读语料后编写，非独立专家盲标。120 次本地检索、无生成或付费 API 调用。改变的是候选池扩展与去重组合，不单独归因给某一个动作。

## 中文查询自动翻译：同60查询开发对照

保持Document接口与索引不变，仅12条中文查询通过本地Qwen自动翻译一次，译文在检索前保存。指定目标Recall@8为67/76→76/76（88.2%→100%），中文切片6/15→15/15；MRR为0.8032→0.9394。48条英文候选序列不变。翻译12次全部成功，中位4.44秒，范围3.58–14.70秒。该集合已用于定位语言问题，不是独立盲测。

[公开查询、目标和排名](evaluation/retrieval-60-rankings.json)可用脚本重算指标，不包含论文全文或私密数据库。

## 托管模型：12 题质量评测

Web、Collection、Hybrid 各 4 题。每题 5 个固定检查项，以助手离线对照报告与当次保存来源评审；覆盖至少 4/5，核心交付成立，且无核心事实错误或来源模式违规，记为完成。

当前 H-off：故障恢复视图 11/12（91.7%），抽样声明完全支持 58/60（96.7%）。指定连接故障位置使用恢复尝试，其他保留首次；原失败与费用保存在研发仓库。

该评测的Web工具使用题单指定官方域名硬白名单；正常网页入口未默认应用此白名单。因此11/12是指定来源条件下的交付验证，不写成自由Web产品入口的实测完成率。抽样支持率不是全报告逐句正确率；助手非盲离线复核不是独立人类盲评。

P1-H 对照同样 11/12，当前版统一费率费用高约 18.3%。该对照属于最终候选选型，不主张整体完成率或成本改善。费用来自已报告 token 估算，不是账单。

## 本地模型：30 题固定评测

Qwen v6.2原归档：首次16/30，指定连接故障恢复后17/30。复核C02后纠正了“引用论文数字即视为违规”的评分错误；纠正视图首次17/30（56.7%）、指定恢复后18/30（60.0%），三模式6/10、7/10、5/10。覆盖得分119.5/150，抽样声明完全支持112/150保持不变。该变化是评分纠错，不是算法收益。10个文库任务的25个任务—论文目标全部发现并读取；这是多轮任务级覆盖，不是单查询Recall@1。

后续版本处于开发验证，旧成绩不追改为新版成绩。当前公开准备重点是条件保留、多来源综合与官方实现核查。

恢复视图runtime complete为11/30，与质量完成18/30分开。Qwen为需求驱动workflow，不用托管路线的多智能体名称替代其实际结构。
